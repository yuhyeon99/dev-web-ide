## 생성된 영상 파일

`video/dev-web-ide-demo.webm` 파일을 생성했습니다.

이 영상은 `demo-video-source.html`의 캔버스 애니메이션을 브라우저 `MediaRecorder`로 녹화한 무음 WebM 파일입니다. 화면 하단에 설명 자막이 포함되어 있어 별도 음성 없이 제출할 수 있습니다.

## 자막 파일

`demo-script-and-subtitles.vtt`를 사용합니다.

## 직접 녹화 시 권장 순서

1. 배포 사이트 또는 로컬 FE를 연다.
2. 대시보드에서 프로젝트 목록을 보여준다.
3. 팀 프로젝트 생성 모달을 열고 회원 검색 필드를 보여준다.
4. 공유 프로젝트 영역을 보여준다.
5. 워크스페이스로 이동한다.
6. 파일 트리에서 파일을 선택한다.
7. Monaco Editor에서 코드를 수정한다.
8. Save 버튼을 누른다.
9. Run 버튼을 눌러 터미널 출력을 보여준다.
10. Team Chat 패널에 메시지를 입력하는 장면을 보여준다.

## 제출 팁

- 음성 없이 화면 녹화만 제출해도 `demo-script-and-subtitles.vtt`를 함께 제출하면 설명 흐름이 보완됩니다.
- 영상 포맷 제한이 있으면 WebM을 MP4로 변환해서 제출합니다.
- 변환 도구가 없으면 macOS QuickTime 또는 온라인 변환 도구를 사용할 수 있습니다.
