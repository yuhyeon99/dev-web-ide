# Dev Web IDE 발표 대본

## 1. 인트로

안녕하세요. 이번 프로젝트는 브라우저에서 바로 개발할 수 있는 Web IDE 플랫폼, Dev Web IDE입니다.

이 서비스는 사용자가 로컬 개발 환경을 직접 설치하지 않고도 프로젝트 생성, 파일 편집, 저장, 실행, 팀 협업을 웹에서 진행할 수 있도록 만드는 것을 목표로 했습니다.

## 2. 문제 정의

개발 환경을 처음 구성할 때는 언어별 런타임, 패키지, IDE, 실행 환경을 맞추는 데 시간이 많이 듭니다.

특히 팀 프로젝트에서는 모든 팀원이 같은 환경을 맞추기 어렵고, 파일 공유나 협업 편집도 별도의 도구에 의존하게 됩니다.

그래서 저희는 브라우저에서 프로젝트를 만들고, 파일을 편집하고, 실행하고, 팀원과 협업할 수 있는 웹 기반 개발 환경을 만들었습니다.

## 3. 핵심 기능

첫 번째는 프로젝트 생성입니다.

게스트는 빠르게 임시 프로젝트를 만들 수 있고, 회원은 Google OAuth로 로그인한 뒤 개인 프로젝트와 팀 프로젝트를 만들 수 있습니다.

두 번째는 파일 트리와 코드 에디터입니다.

프로젝트 파일 트리는 백엔드 API에서 실제 파일 구조를 받아 표시하고, 사용자는 파일과 폴더를 추가할 수 있습니다.

중앙의 코드 에디터는 Monaco Editor를 사용했고, 파일 확장자에 따라 TypeScript, Python, Java, C++ 등의 언어 모드를 자동 적용합니다.

세 번째는 저장과 실행입니다.

Save 버튼을 누르면 변경된 파일만 백엔드 저장 API로 전달되고, 백엔드는 파일 메타데이터를 RDS에 저장하고 실제 파일은 EFS에 저장합니다.

Run 버튼을 누르면 프로젝트 실행 API를 호출하고, 실행 세션과 컨테이너 정보를 터미널 패널에 표시합니다.

네 번째는 팀 협업입니다.

팀 프로젝트 생성 시 실제 가입된 회원을 검색해서 초대할 수 있습니다. 초대받은 사용자는 대시보드의 공유 프로젝트 영역에서 프로젝트를 확인하고 워크스페이스로 진입할 수 있습니다.

워크스페이스에서는 Yjs 기반 CRDT 구조로 같은 파일을 실시간 공동 편집할 수 있고, WebSocket 기반 팀 채팅도 사용할 수 있습니다.

## 4. 시스템 아키텍처

프론트엔드는 React, TypeScript, Vite로 구현했고, 빌드 결과물은 S3에 배포했습니다. 사용자는 CloudFront를 통해 HTTPS로 프론트엔드에 접근합니다.

백엔드는 Spring Boot로 구현했고 Docker 이미지로 빌드한 뒤 ECR에 저장합니다. 실제 실행은 ECS Fargate에서 담당합니다.

API 트래픽은 CloudFront와 ALB를 거쳐 ECS 서비스로 전달됩니다.

데이터베이스는 RDS MySQL을 사용합니다. 사용자, 프로젝트, 파일 메타데이터, 프로젝트 멤버, 저장 이력 같은 구조화된 데이터를 저장합니다.

프로젝트 파일 원본과 버전 파일은 EFS에 저장해서 ECS task가 재배포되어도 파일이 유지되도록 했습니다.

실시간 기능은 WebSocket/STOMP와 Redis Pub/Sub 구조로 구현했습니다. 프로젝트 이벤트, CRDT 편집 업데이트, 팀 채팅 메시지를 Redis 채널로 전달해 여러 서버 인스턴스에서도 확장 가능한 구조를 만들었습니다.

## 5. 시연 안내

시연에서는 먼저 대시보드에서 프로젝트 목록을 확인합니다.

다음으로 팀 프로젝트 생성 모달에서 실제 회원을 검색하고 초대하는 흐름을 보여드립니다.

그 뒤 초대받은 계정에서 공유 프로젝트가 표시되는 것을 확인합니다.

워크스페이스에서는 파일 트리, 파일 생성, Monaco Editor 편집, Save 버튼, Run 버튼을 차례로 시연합니다.

마지막으로 팀 프로젝트에서 실시간 공동 편집과 팀 채팅 UI를 보여드립니다.

## 6. 구현 성과

이번 프로젝트에서는 단순한 화면 구현이 아니라 실제 클라우드 배포와 API 연동까지 포함한 end-to-end Web IDE를 구현했습니다.

S3, CloudFront, ECS, ECR, RDS, EFS, Redis 구조를 적용했고, GitHub Actions를 통한 CI/CD도 구성했습니다.

또한 OAuth 로그인, 팀원 초대, 공유 프로젝트, 파일 저장, 실시간 편집, 채팅까지 웹 IDE의 핵심 사용자 흐름을 실제 동작 가능한 형태로 연결했습니다.

## 7. 향후 개선

향후에는 ElastiCache Redis를 운영 환경에 완전히 연결하고, DB/JWT secret을 Secrets Manager로 이전할 계획입니다.

또한 터미널 로그 실시간 스트리밍, CRDT 스냅샷 복구, 팀 초대 수락 UX, 커스텀 도메인 적용을 개선할 수 있습니다.

이상으로 Dev Web IDE 발표를 마치겠습니다.
