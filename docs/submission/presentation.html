Demo Flow

시연 순서

  • 대시보드에서 최근/내/공유 프로젝트 확인
  • 팀 프로젝트 생성 시 실제 회원 검색 후 초대
  • 초대받은 계정에서 공유 프로젝트 확인
  • 워크스페이스에서 파일 트리, 파일 생성, 코드 편집
  • Save 버튼과 Run 버튼 동작 확인
  • 팀 채팅과 CRDT 공동 편집 구조 설명
Result

구현 성과
